# ScriptPlayer+ 업데이트와 복구

[English](UPDATE_AND_RECOVERY.md)

## 업데이트 전 백업

1. 재생을 멈추고 앱에서 장치 연결을 해제한 뒤 앱을 완전히 종료합니다.
2. 사용자 데이터 폴더 전체를 별도 백업 폴더에 복사합니다. 원래 폴더는 유지합니다.
3. 이전 공식 설치 파일 또는 ZIP과 해당 버전을 보관합니다.

| 운영체제 | 기본 사용자 데이터 위치 |
| --- | --- |
| Windows | `%APPDATA%\scriptplayer-plus` |
| macOS | `~/Library/Application Support/scriptplayer-plus` |
| Linux | `~/.config/scriptplayer-plus` 또는 지정한 XDG 설정 경로 |

`--user-data-dir`나 개발용 프로필을 지정했다면 실제 위치가 달라집니다. Windows ZIP과 설치본은 기본적으로 같은 프로필을 사용합니다. 새 폴더에 ZIP을 풀어도 프로필이 격리되지는 않습니다.

라이브러리 목록뿐 아니라 설정, 로컬 저장소, IndexedDB, 사용자 썸네일과 플러그인 설정을 포함해 폴더 전체를 백업합니다. 목록 파일만 복사하면 평점·최근 파일·오프셋 등을 모두 보존할 수 없습니다. 외부에 저장된 원본 영상·스크립트는 이 백업에 포함되지 않습니다.

## 설치 후 확인

Windows 설치본은 공식 Setup으로 업데이트하고, ZIP은 새 앱 폴더에 풉니다. 설정에서 버전을 확인한 뒤 라이브러리·즐겨찾기·기존 영상과 스크립트·장치 설정을 점검합니다.

외장 드라이브나 NAS가 꺼져 있다면 먼저 다시 연결합니다. 소스가 보이지 않는다는 이유로 앱을 초기화하거나 라이브러리 목록을 지우지 마세요.

## 이전 버전 복원

1. 새 버전을 완전히 종료합니다.
2. 현재 프로필도 다른 이름의 백업으로 보관합니다.
3. 업데이트 전의 전체 프로필 백업과 그때 사용했던 공식 앱 버전을 함께 복원합니다.
4. 라이브러리, 평점, 오프셋, 장치 설정과 영상·스크립트 재생을 확인합니다.

새 버전이 저장한 프로필을 이전 앱이 읽을 수 있다고 가정하지 마세요. 프로필 형식을 자동으로 되돌리거나 두 백업을 합치지 않습니다. 복원하면 설정은 백업 시점으로 돌아갑니다.

## 오류 제보

앱 버전, 패키지 종류, 운영체제, 저장장치 종류, 재현 순서, 기대 결과와 실제 결과를 적어 주세요. 재생 지연은 장치의 진단 화면에서 문제 보고서를 복사합니다. 가림 처리된 보고서에도 파일명이 남을 수 있으니 공개 전에 확인하세요. 전체 프로필, 개인 미디어, 연결 키, 페어링 토큰이나 네트워크 비밀번호는 첨부하지 마세요.
