# ScriptPlayer+ 0.6.2

[English](v0.6.2.md)

RC5까지의 재생 안정성 수정과 라이브러리·장치·업데이트 개선을 통합한 정식 버전입니다.

## 배포 파일

- Windows x64: Setup 설치 파일과 ZIP.
- macOS Apple Silicon·Intel: 아키텍처별 DMG와 ZIP.
- Linux x64: AppImage, DEB, tar.gz. Ubuntu 24.04에서 비특권 사용자 네임스페이스가 제한된다면 DEB를 사용해 주세요.

9월 10일 배포 파일을 다시 구성하면서 js-yaml과 빌드 도구의 간접 의존성도 패치 버전으로 갱신했습니다. 먼저 공개됐던 Windows 전용 0.6.2를 설치했다면 새 Setup을 받아 다시 설치해야 이 패치가 적용됩니다. 앱 버전 번호는 0.6.2로 유지됩니다.

## 재생과 저장장치 처리

- 같은 저장장치에서 영상 재생·탐색을 우선 처리하고, 썸네일·재생시간·내장 트랙 읽기를 조정합니다. 네트워크 드라이브의 서로 다른 경로도 함께 조정합니다.
- 자막과 펀스크립트를 비동기로 읽고 기본 스크립트를 먼저 적용합니다. 선택 가능한 스크립트 변형은 별도로 탐색합니다.
- 스크립트 변형을 찾는 동안 자동 빈 구간 건너뛰기가 충돌하는 문제와 빠른 영상 전환 시 이전 파일의 결과가 적용되는 문제를 방지합니다.
- Windows에서 네이티브 파일 읽기를 사용하며 시작에 실패하면 기존 스트리밍 경로로 전환합니다.
- 화면에 보이는 썸네일을 우선 처리하고, 기존 썸네일의 불필요한 재생시간 조사와 중복 폴더 탐색을 줄입니다.

## 라이브러리·장치·업데이트

- 라이브러리 폴더 탐색과 파일 사이드바의 폴더 구분을 제공합니다.
- 폴더를 라이브러리에 저장하지 않고 임시로 열 수 있습니다. 기존 자동 저장 방식은 기본값으로 유지합니다.
- 같은 이름의 영상에 외부 스크립트가 잘못 자동 연결되지 않도록 비동기 읽기 경로도 보호합니다.
- 스크립트별 동작 범위를 유지하고 FunSR Pro 연결 상태·포트 안내와 프리셋 축별 켜기·끄기를 개선합니다.
- Android 리모컨 호환성, Windows 업데이트 진행 표시·설치 프로그램 실행·바로가기 보존을 개선합니다.
- 진단 보고서에 재생 시작·탐색 시간, 대기·멈춤 이벤트, 응답 지연과 스크립트 변형 탐색 정보를 추가합니다.

## 업데이트 전 확인

앱을 완전히 종료한 뒤 사용자 데이터 폴더 전체를 백업해 주세요. Windows ZIP도 기본적으로 설치본과 같은 프로필을 사용합니다. [업데이트·복구 안내](../UPDATE_AND_RECOVERY_KO.md)를 참고해 주세요.

FFmpeg는 별도 설치 방식입니다. 기존 EULA와 제3자 라이선스는 유지됩니다. Windows 파일은 미서명이며 macOS 파일은 임시 서명을 사용하고 Apple 공증은 받지 않았습니다.

## 확인 범위

제보자의 실물 HDD에서의 개선 효과와 Handy·Intiface·직렬 장치·리모컨의 실물 재연결은 별도 확인이 필요합니다. 자동 테스트나 합성 영상 결과가 모든 환경의 멈춤 문제 해결을 보장하지는 않습니다.
