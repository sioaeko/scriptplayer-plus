# ScriptPlayer+ 0.6.2

[한국어](v0.6.2.ko.md)

This release combines the main development changes with the fixes through the updated 0.6.2-rc.5 build.

## Playback and slow storage

- Prioritize playback and seeking over thumbnail, duration, and embedded-track work on the same storage device. Network-drive aliases share the same coordination.
- Read subtitles and funscript sidecars asynchronously, apply the direct script first, and discover optional Script Variants separately.
- Guard automatic gap skipping during deferred variant discovery and protect rapid media changes from stale results.
- Use the native Electron file-fetch path on Windows, with the existing streaming path as a startup fallback.
- Prioritize visible thumbnails, reuse existing images without redundant duration probes, and use metadata-only preload for direct thumbnail capture.
- Avoid redundant XTP folder scans for ordinary filenames containing a separator.

## Library, devices, and updates

- Add folder navigation in the library and preserve folder grouping in the Files sidebar.
- Allow opened folders to remain temporary when “Save opened folders to library” is disabled; the existing save behavior stays enabled by default.
- Preserve duplicate-name protection when automatically matching external scripts, including the asynchronous playback path.
- Keep stroke range settings specific to each script, improve FunSR Pro connection-state and port feedback, and allow supported axes to be toggled in preset profiles.
- Improve Android desktop remote compatibility and Windows update progress, installer launch, and shortcut handling.
- Extend copied diagnostics with playback startup and seek timings, waiting/stalled events, heartbeat gaps, and variant-discovery activity.

## Before updating

Close the application and back up its user-data directory. Windows ZIP builds use the same user profile as the installed application unless explicitly isolated; extracting into another folder does not create a separate profile. See [update and recovery instructions](../UPDATE_AND_RECOVERY.md).

FFmpeg remains an optional external dependency. It is not bundled. The existing EULA and third-party license terms continue to apply.

## Known validation limits

- Improvement on the reporting user's physical slow HDD still needs confirmation. Do not interpret automated tests or synthetic media checks as proof that every HDD stall is fixed.
- Physical Handy, Intiface, serial-device, and remote reconnection checks must be recorded separately from software tests.
- Windows binaries are unsigned. macOS packages use ad-hoc signing and are not notarized.
