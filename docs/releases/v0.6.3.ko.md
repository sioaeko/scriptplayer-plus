# ScriptPlayer+ 0.6.3

[다운로드](https://github.com/sioaeko/scriptplayer-plus/releases/tag/v0.6.3)

Windows x64는 설치 프로그램·ZIP, macOS ARM64는 DMG·ZIP, Linux x64는 AppImage·DEB·tar.gz를 제공합니다. 업데이트 전 앱을 종료하고 사용자 데이터 폴더를 백업해주세요. Windows ZIP과 설치형은 별도로 격리하지 않으면 같은 사용자 프로필을 사용합니다. [업데이트·복구 안내](https://github.com/sioaeko/scriptplayer-plus/blob/master/docs/UPDATE_AND_RECOVERY_KO.md)

Windows 파일은 서명되지 않았으며 macOS 파일은 ad-hoc 서명이고 공증되지 않았습니다. FFmpeg는 선택적인 외부 의존성이며 번들에 포함하지 않습니다.

- 이번 버전부터 macOS 배포 파일은 Apple Silicon(ARM64)용 DMG·ZIP만 제공합니다. Intel(x64)용 신규 빌드는 제공하지 않습니다.

- 전원을 켠 Handy에 처음 연결할 때 스크립트 모드를 확인한 뒤 정지 명령을 보내도록 수정했습니다. 기본 모드에서 정지 요청이 거절되어 첫 스크립트 준비가 막히는 문제를 방지합니다.

- 여러 Handy의 연결키를 등록해 같은 영상과 스크립트를 함께 재생할 수 있습니다. 장치별 이름·출력 범위(0–100%)·오프셋(±5,000ms)을 설정하며, 준비가 먼저 끝난 장치부터 재생하고 늦게 준비되거나 연결한 장치는 현재 위치에 합류합니다. 최대 8개 장치를 등록할 수 있으며 이는 등록 한도입니다.
- Handy마다 출력 정지·재개·연결 해제·오류 재시도를 제공합니다. 한 장치의 준비·재생 실패를 다른 장치와 구분해 표시하며, 정지가 확인되지 않으면 재생을 차단하고 정지를 다시 시도할 수 있습니다. 기존 전체 장치 정지 버튼도 연결한 Handy 전체에 적용됩니다.
- 영상 일시정지 후 다시 재생할 때 Handy가 멈춰 있거나 늦게 반응하는 문제를 수정했습니다. 정지 응답을 기다린 뒤 현재 영상 위치로 재개하며, 일시적인 재생 오류에는 준비된 스크립트를 다시 사용합니다. 일시정지 확인이 실패했다면 다음 재생 시 정지를 한 번 더 확인한 뒤 재개합니다. 개별 출력 정지는 유지하며, 다시 일시정지하면 대기 중인 재개도 취소합니다.
- Handy 연결키와 장치별 설정은 OS 암호화로 저장합니다. 암호화를 사용할 수 없으면 새 키를 평문으로 저장하지 않고 이번 실행에서만 사용합니다. 기존에 사용하던 연결키 한 개를 이전하며, 과거 연결 이력을 모두 자동 등록하지는 않습니다. 저장된 장치의 자동 연결은 사용자가 선택할 수 있습니다.

- 영상별 재생 횟수 표시와 많이 본 순·적게 본 순 정렬을 추가했습니다. 실제 재생 5초를 기준으로 기록하며, 10초 미만 영상은 길이의 절반을 기준으로 합니다. 한 번 열어 재생하는 동안 일시정지·탐색·반복 재생은 중복 집계하지 않습니다. 기록은 앱 재시작 후에도 유지되며 업데이트 이후부터 쌓입니다. 파일 경로가 바뀌면 별도 영상으로 집계됩니다.
- 라이브러리의 ‘속도·그룹’에서 자동 매칭된 스크립트의 평균 이동 속도로 검색할 수 있습니다. 느림·보통·빠름, 직접 범위 입력과 속도 미확인 필터를 제공하며 카드에 분석 축과 평균 속도를 표시합니다. 원본의 처음~마지막 지점 사이 정지 구간을 포함한 %/초 기준이며, 통합 다축 파일은 L0를 우선합니다. 재생 배속과 증폭 설정은 반영하지 않습니다.
- 현재 검색 결과를 이름 붙인 그룹으로 저장하고, 재실행 후에도 그룹을 플레이리스트로 불러올 수 있습니다. 그룹 이름 변경·삭제를 지원하며 그룹 삭제는 영상·스크립트 파일을 삭제하지 않습니다. 그룹은 저장 시점의 결과 목록을 유지합니다.
- 속도 분석은 직접 시작·중지할 수 있고 재생 중에는 대기합니다. 분석 결과는 캐시에 저장하며 다시 분석할 때 파일 크기·수정 시각이 같으면 재사용합니다. 스크립트 수정 후에는 ‘스크립트 분석·갱신’을 눌러 갱신할 수 있습니다.

- Files의 별점 정렬은 기본적으로 전체 목록을 비교합니다. “폴더별로 정렬”을 선택하면 기존 폴더 구분을 유지하며 이전·다음 재생도 같은 순서를 따릅니다.
- 라이브러리나 다른 메뉴에서 Files로 돌아올 때 현재 선택한 영상을 목록 중앙에 표시합니다. 선택 항목이 목록에 없으면 이전 스크롤 위치를 복원하며, 접어 둔 폴더는 유지합니다.
- 느린 저장장치 호환 옵션에 드라이브별 썸네일 동시 작업 수와 재생 중인 드라이브의 썸네일 보류 동작을 연결했습니다. 기본값은 꺼짐이며, 중복 읽기 제거와 짧은 로딩 구간의 우선 처리는 공통으로 유지합니다.
- Range Extender를 50–500%로 확대하고 직접 수치 입력을 추가했습니다. 기본 증폭은 기존 동작을 유지합니다. 미세 움직임 보존은 끝부분이 평평하게 잘리지 않는 곡선으로 증폭합니다. 양 끝 출력은 원본 50% 미만을 설정한 최솟값, 50% 이상을 최댓값으로 변환합니다. 방식은 스크립트별 범위 설정과 함께 저장되며 출력 범위·속도 제한은 유지합니다.
- 숫자키 0–9로 재생 위치의 0–90%를 탐색합니다. 입력창에서의 숫자 입력과 기존 사용자 지정 단축키를 보존합니다.
- 라이브러리 카드에서 기존 휴지통 이동 기능을 사용할 수 있습니다. 영상 파일만 이동하고 스크립트 파일은 보존합니다.
- R0 저소음 처리와 변경된 축만 전송하는 옵션을 포함합니다. 주기적인 전체 값 갱신과 정지 명령은 유지하며 STR에서 원본·출력 범위와 클리핑 정보를 확인할 수 있습니다.
- 스크립트 탐색 캐시·취소 처리와 탐색 진단을 개선했습니다.
- 독립 Roll(R1)·Pitch(R2) 랜덤 움직임을 추가했습니다. 축마다 활성화·속도·범위를 설정하며 기본값은 꺼짐입니다. L0 스크립트와 함께 동작하고, 기존 축 스크립트나 축 연결 설정을 우선합니다. 실제 출력에는 기존 축별 범위·반전·속도 제한이 적용됩니다.
- 스크립트 도구에 실험 기능인 **Jev 생성·검토**를 추가했습니다. 랜덤 패턴 생성, 0.5–24초 영상 클립 분석 보조, FunGen 등에서 만든 `.funscript`의 0.5–24초 구간 검토를 제공합니다. 원본/완화 곡선을 비교하고 구간별 판단을 직접 바꾸거나 되돌린 뒤 저장할 수 있습니다.
- Jev는 별도 TypeSafe API 키가 필요하며, 생성·검토 시 유료 API 요청이 발생합니다(전체 휴식 패턴 제외). 영상·음성·파일 경로는 전송하지 않습니다. 미리보기는 장치를 움직이지 않으며, 스크립트 구간 검토 결과는 **선택한 구간만 0초부터 저장**하므로 해당 영상 클립과 사용해야 합니다. 자동 품질 향상은 입증되지 않았고, 장편 영상 생성·전체 스크립트 병합은 포함하지 않습니다.
- 내장 자막을 빠르게 전환하거나 끈 뒤 이전 추출 결과가 뒤늦게 적용되는 문제를 방지했습니다. 0.6.2 최종 배포의 의존성 보안 수정과 패키지 내부 의존성 누락 검사도 유지합니다.

2026-09-26 Windows 설치 후보에서 실제 Handy 두 대로 재생, 일시정지 후 재개, 빠른 일시정지·재개, 탐색, 전체 출력 정지를 검증했습니다. 두 장치 모두 명령을 정상 수락했고 마지막 정지 상태를 확인했으며, 사용자가 두 대의 실제 움직임을 확인했습니다. 이 검증은 48–52%의 느린 테스트 스크립트에 한정하며 정밀한 기계적 동기화나 재생 중 연결 끊김·재연결까지 보장하지 않습니다. 8대 등록 한도를 8대 실기기 검증으로 해석해서는 안 됩니다. macOS ARM64 기동·서명 검사와 Linux 패키지 압축 해제·headless 기동 검사를 완료했습니다. Linux GPU 영상 재생·시스템 DEB 설치, 실제 HDD·NAS 지연, 직렬 장치의 움직임·소음은 이번 검사로 확인한 범위가 아닙니다. 실시간 스크립트 녹화와 Handy·Intiface 직접 동시 출력은 별도 개발 항목이며 이번 변경에 포함되지 않습니다.
