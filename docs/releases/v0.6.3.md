# ScriptPlayer+ 0.6.3

## September 26 package correction

The v0.6.3 downloads were rebuilt to fix an empty library after opening a saved group and choosing **Clear playlist**. Clearing the playlist now returns to the registered library immediately, including after restarting with a saved group open. Saved groups, media and scripts are preserved.

If you already installed v0.6.3 before this correction, download and install the replacement manually. The version remains 0.6.3, so the updater will not offer it as a newer version.

This update adds multiple-Handy playback, independent random Roll/Pitch, and new ways to search and organize your library.

## Downloads

- Windows x64: Setup installer and ZIP.
- macOS Apple Silicon (ARM64): DMG and ZIP. Starting with 0.6.3, new Intel Mac builds are no longer provided.
- Linux x64: AppImage, DEB and tar.gz. Use the DEB on Ubuntu systems that restrict unprivileged user namespaces.

## Changes

- Fixed first script preparation being blocked when a newly connected Handy is still in its default motion mode. The player selects script mode before sending the stop command.
- Returning to Files brings the selected video into view. If it is no longer in the list, the previous scroll position is restored. Collapsed folders are preserved.

- Connect multiple Handys to the same media and script. Each device has its own name, output range (0–100%) and offset (±5,000 ms). Ready devices can start while others prepare; late devices join the current playback position. Up to eight devices can be registered; this is a registration limit.
- Stop, resume, disconnect or retry each Handy independently. Preparation and playback errors are shown per device. An unconfirmed stop blocks playback until stop can be retried. The existing global device-stop button also addresses every connected Handy.
- Fixed Handy remaining stopped or resuming late after pausing and playing the video. Resume timing now follows the current media position after the stop response, and transient playback errors reuse the prepared script. A subsequent media play retries an unconfirmed pause stop once and resumes only after acknowledgement. Individually stopped outputs stay stopped; pausing again cancels queued playback.
- Save Handy keys and per-device settings using OS encryption. When encryption is unavailable, new keys remain in memory for the session without a plaintext fallback. Only the previously active key is migrated, rather than automatically registering the entire connection history. Automatic connection of saved devices is optional.

- Added per-video play counts and sorting from most or least played. Counts require five seconds of actual playback, or half the duration for clips shorter than ten seconds. Pausing, seeking and looping do not add counts within the same open session. Counts persist across restarts and begin accumulating after the update; changed file paths are tracked separately.
- Library's “Speed & groups” filters automatically matched scripts by average movement speed: Slow, Medium, Fast, custom bounds and unknown speed. Cards show the analyzed axis and average in position %/s over the first-to-last action span, including holds. Combined scripts prefer L0. Playback rate and Range Extender settings are excluded.
- Save the current search results as named groups, reopen them as playlists after restarting, rename them or remove them without deleting media or scripts. Groups retain the list captured when saved.
- Script analysis runs on demand with cancellation and pauses during playback. Results are cached locally; analyzing again reuses unchanged file sizes and modification times. Use “Analyze / refresh scripts” after editing scripts.

- Files rating sorting now compares the whole list by default. A “Sort within folders” option preserves folder browsing and uses the same order for previous/next playback.
- Slow Storage Compatibility now also controls per-drive thumbnail concurrency and the hold on thumbnails from the playing drive. It remains off by default. Duplicate-read reductions and short foreground load coordination remain shared improvements.
- Range Extender supports 50–500% and direct number entry. Standard mode retains the previous clipping behavior. Preserve Detail uses a continuous curve without flat clipped tails. Endpoints maps source values below 50% to the selected minimum and values at or above 50% to the maximum. The mode is saved with each script's amplitude preference; output range and speed limits still apply.
- Number keys 0–9 seek to 0–90% of the current media. Text entry and existing customized shortcut assignments are respected.
- Library cards expose the existing Move to Trash action. It moves the media file only and preserves script files.
- Serial output options include R0 quiet filtering and sending only changed axes, with periodic complete refreshes and stop commands preserved. The STR panel shows source/output ranges and clipping information.
- Script discovery caching, cancellation and seek diagnostics are improved.
- Added independent random Roll (R1) and Pitch (R2) motion, with separate enable, source speed and range settings. Both default off and accompany an L0 script. Existing axis scripts and source links take precedence; normal per-axis range, inversion and speed limits still apply.
- Added experimental **Jev generation and review** to Script tools: random patterns, local analysis assistance for 0.5–24-second video clips, and review of 0.5–24-second sections from `.funscript` files produced by FunGen or other tools. Compare original and softened curves, change or restore each section's choice, then save the result.
- Jev requires a separate TypeSafe API key and makes a paid request when generating or reviewing, except for rest-only patterns. Video, audio and local paths are not sent. Preview does not move devices. Script review exports **only the selected section, starting at zero**, for use with its matching video clip. Automatic quality improvement has not been demonstrated; long-video generation and merging sections into a full script are not included.
- Prevented stale embedded-subtitle extraction results from applying after a newer selection or disabling subtitles. Retained the final 0.6.2 dependency security fixes and checks for missing runtime dependencies inside packaged apps.

## Updating and validation

Two physical Handys were checked on the Windows release candidate using a short, slow script: playback, pause/resume, rapid pause/resume, seeking and global stop. Both devices accepted commands and the user confirmed both moving. This does not establish exact mechanical synchronization, reconnection stress behavior or eight-device hardware operation.

Windows installation, macOS ARM64 launch/signature checks, and Linux package extraction/headless launch checks were completed. Linux GPU playback and system DEB installation were not newly validated. Physical HDD/NAS timings and serial-device motion/noise remain separate validation areas. Live script recording and simultaneous direct Handy/Intiface output are not included.

Close the app and back up its user-data directory before updating. Windows ZIP and installed builds share the same profile unless explicitly isolated. See the [update and recovery guide](https://github.com/sioaeko/scriptplayer-plus/blob/master/docs/UPDATE_AND_RECOVERY.md).

Windows binaries are unsigned. macOS packages are ad-hoc signed, not notarized. FFmpeg remains an optional external dependency and is not bundled. Existing EULA and third-party license terms continue to apply.
